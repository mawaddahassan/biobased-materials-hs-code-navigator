# Bio-based Materials HS Code Navigator

A preliminary HS code dictionary for bio-based materials, with an Excel navigator for browsing and grouping the codes.

## Why this exists

Bio-based materials matter globally, but identifying and tracking them in international trade statistics is still hard. HS codes often lump bio and non-bio materials together, so trade in bio-based materials is difficult to isolate.

This project builds a structured database of HS codes covering natural fibers, plant-derived materials, natural polymers, bio-based chemicals and more.

## What's inside

Each HS code is placed on the value chain:

| Stage | Meaning |
|---|---|
| **Biomass Feedstock** | Raw biological material |
| **Processed Biomass** | Intermediate, processed material |
| **Bioproduct** | Final bio-based product |

So you can see not just what a material is, but where it sits in the processing chain.

**Scope:** food, feed and energy products are excluded on purpose.

## How to use the navigator

1. Download `Bio-Based Materials HS Code Database.xlsx`
2. Go to the 'Navigator' sheet within the Excel Workbook, choose a tier from the drop-down menu in cell B4, then choose a category from the drop-down below it. The codes alongside their description will appear.
3. Copy the codes for the material you're interested in.
4. Group them in ITC Trade Map (https://www.trademap.org/en/) to analyze trade flows.


## Sources

- Harmonised System — World Customs Organization
- UNCTAD biotrade list (used to cross-check the codes)
- Published literature

## Limitations

- This is a **preliminary** dictionary, not an official classification.
- Some HS codes mix bio and non-bio products, so check the product description before drawing conclusions.
- The HS version used is HS-2022 version.
